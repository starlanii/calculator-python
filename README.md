# 🧮Begginer Python Calculator

A simple but powerful **console-based calculator** written in Python.
Perfect for begginers who want to practice conditionals, functions, user input and math operations :D !

---

## ✨Features
### ✅Basic Operations
- Addition
- Subtraction
- Multiplication
- Division (with zero-division protection)

### 🛡️Error handling
- Invalid menu options
- Division by zero
- Square root of negative numbers
- Prevents crashes when the user enters incorrect input
